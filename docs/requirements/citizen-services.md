## البيانات المشتركة

### طلبات الكروكي

- اسم مقدم الطلب.
- محل مقدم الطلب.
- رقم العقار من مديرية المصالح العقارية.
- اسم المنطقة العقارية من مديرية المصالح العقارية.
- تكليف مساحي من مديرية المصالح العقارية، مع إحداثيات `X` و`Y` دقيقة جدًا.
- دفع رسم الطلب: `9700` ليرة سورية.

### الاستعلامات

- اسم مقدم الطلب.
- رقم الهاتف الجوال.
- نص موضوع الاستعلام.

## أنواع الاستعلامات

### شراء فضلة

المرفقات المطلوبة: مخطط كروكي حديث، وتكليف مساحي يتضمن إحداثيات `X` و`Y` دقيقة جدًا.
المخرج رد نصي يتضمن التفاصيل الخاصة بالفضلة.

### دمج عقارين

المرفقات المطلوبة: بيان قيد عقاري للعقار الأول وبيان قيد عقاري للعقار الثاني من
مديرية المصالح العقارية. المخرج رد نصي يتضمن تفاصيل إمكانية الدمج وشروطه.

### الوضع التنظيمي

لا يتطلب مرفقات إضافية. المخرج رد نصي يوضح الوضع التنظيمي للعقار.

## دورة الطلب الموحدة

```text
النافذة الواحدة
  → الديوان العام
  → ديوان الشؤون الفنية
  → بريد دائرة التخطيط العمراني حسب الشعبة
  → إعداد الخدمة والرد النصي وصفحة الصور المرفقة
  → توقيع الرسامة والمدقق
  → توقيع ومصادقة رئيس قسم الشؤون الفنية
  → توقيع مدير المدينة وختمه
```

## مخطط التسلسل

يوضح مخطط `Sequence` الموجود في `.software/diagrams/citizen-services-sequence.json`
انتقال الطلب بين المشاركين بالترتيب التالي:

```text
مقدم الطلب → النافذة الواحدة → الديوان العام → ديوان الشؤون الفنية
→ بريد دائرة التخطيط العمراني → الرسامة والمدقق
→ رئيس قسم الشؤون الفنية → مدير المدينة
```

يُستخدم التسلسل نفسه للطلبات والاستعلامات، مع اختلاف البيانات والمرفقات والمخرج.
وقد يرجع مخطط الكروكي من الرسامة والمدقق أو رئيس قسم الشؤون الفنية لاستكمال
المعلومات قبل المتابعة.

## حالات إعادة مخطط الكروكي

يمكن إعادة المخطط إلى المواطن من فريق الرسامة والمدقق عند:

1. فتح التكليف المساحي الصادر عن البلدية دون وجود إحداثيات في النظام الخاص به.
2. تشابه رقم العقار مع عقار آخر في المنطقة نفسها، للعقارات المؤقتة فقط.
3. تعذر معرفة كيفية الدخول إلى العقار.
4. شك المدقق بأن العقار مفرز.

ويستطيع رئيس دائرة التخطيط العمراني أو مدير الشؤون الفنية إعادة أي مخطط كروكي
عند وجود شك، بعد دراسة شخصية. أما توقيع مدير المدينة فهو توقيع شكلي مع الختم.

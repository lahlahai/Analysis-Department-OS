# التوثيق الأساسي للنظام

هذا المجلد هو مرجع المعرفة الوظيفية والمعمارية التي تُقرأ وتُراجع إلى جانب ملفات
`.software`. تبقى ملفات JSON مصدر البيانات المنظمة، بينما تحفظ ملفات Markdown
السياق الوظيفي، الإجراءات، المسؤوليات، والقرارات.

## المجالات الموثقة

- [دائرة التخطيط العمراني في بلدية مدينة حماة](./hama-urban-planning-department.md)

## قاعدة توثيق دراسة أي مديرية

يجب أن يحتوي ملف دراسة المديرية على:

1. الجهة والمرجعية الإدارية.
2. الوحدات التنظيمية والأدوار الوظيفية.
3. المهام والإجراءات كما وردت في المصدر.
4. المدخلات والمخرجات واللجان والجهات المتداخلة.
5. المراجع القانونية مع إبقاء النص الأصلي عند وجود شك في القراءة.
6. نقاط الربط المقترحة مع مخططات `ERD` و`Flowchart` و`Workflow` و`Process diagram`.

لا تُعامل الصور أو المستندات المصدرية كبديل عن التوثيق النصي؛ بل تُحفظ كمرجع
للمراجعة، وتُسجل الحقول غير المحسومة في قسم مستقل قبل اعتمادها.

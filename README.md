# Analysis Department OS

للاطلاع على الوصف الكامل للتحديثات والخصائص الحالية، راجع [UPDATES_AR.md](UPDATES_AR.md).

نظام تشغيل وتحليل إداري يهدف إلى تنظيم بيانات الأقسام والمديريات، وتسهيل إدخال المعلومات ومراجعتها ومتابعة التعديلات التي تُجرى على المستودع.

## فكرة المشروع

يوفّر النظام مساحة عمل عربية تجمع بين:

- تنظيم الملفات ضمن مجلدات واضحة.
- إنشاء ملفات بيانات قابلة للتحرير على شكل جداول شبيهة ببرنامج Excel.
- لصق البيانات مباشرة من Excel باستخدام `Ctrl + V`.
- إضافة وحذف الصفوف والأعمدة وتعديل أسماء الأعمدة.
- عرض سجل تعديلات مستودع GitHub مع رسالة الالتزام واسم المستخدم والوقت النسبي.
- تحديث سجل GitHub تلقائيًا كل دقيقة مع إمكانية التحديث اليدوي.
- فتح الالتزام أو حساب المستخدم مباشرة من سجل التعديلات.

## التقنيات المستخدمة

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- GitHub REST API

## التشغيل محليًا

ثبّت الاعتمادات:

```powershell
npm install
```

شغّل بيئة التطوير:

```powershell
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## ربط GitHub

يقرأ النظام سجل الالتزامات من المستودع:

```text
lahlahai/Analysis-Department-OS
```

يعمل المستودع العام بدون رمز وصول، لكن يُفضّل إضافة رمز GitHub لرفع حد الطلبات.

أنشئ ملفًا باسم `.env.local` وأضف:

```env
GITHUB_TOKEN=github_pat_xxxxxxxxxxxxxxxxx
```

يجب أن يكون الرمز من نوع **Fine-grained personal access token** وبصلاحية:

```text
Contents: Read-only
```

لا ترفع `.env.local` إلى GitHub ولا تشارك رمز الوصول.

## البنية الرئيسية

```text
src/app/api/github/commits/       جلب سجل الالتزامات من GitHub
src/components/editor/           محرر جدول البيانات
src/components/workspace/        مساحة العمل وسجل التعديلات
src/domain/                      أنواع البيانات والتحقق منها
src/lib/                         البيانات التجريبية وتحميل مساحة العمل
```

## الحالة الحالية

النسخة الحالية تركّز على إدخال البيانات وإدارتها في جداول عربية ومتابعة سجل المستودع. تم إيقاف واجهة محرر المخططات مؤقتًا للتركيز على تجربة الجداول وسهولة إدخال البيانات.
